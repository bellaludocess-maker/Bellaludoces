# Estrutura Modular - Bella Lu Doces
Este diretório abriga os módulos independentes (Feature-First):
- `catalog/`: Modelos de produto, repositório e vitrine
- `cart/`: Sacola de compras e seleção de variações/sabores
- `checkout/`: Entrega/Retirada, endereço e envio para WhatsApp
- `external/`: Integrações Firebase Firestore e Cloudinary
- `admin/`: Painel de gestão da loja
